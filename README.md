# OrbitCam · 环绕视角

[简体中文](README.md) · [English](README_EN.md)

Minecraft Fabric 客户端mod，新增类似建模软件的的环绕视角，可以用鼠标拖动平移、绕点旋转和滚轮缩放相机，并释放准星让其在屏幕内自由移动，可无需转动视角交互屏幕内任意方块，支持一键缩放变焦以精准操作。

## 按键

| 键                  | 默认         | 说明                   |
| ------------------- | ------------ | ---------------------- |
| 进入/退出环绕模式   | **F6**       | 唯一入口               |
| 修饰键              | **左 Alt**   | 作用取决于键模式，见下 |
| 旋转                | **鼠标左键** | 拖动相机绕中心旋转     |
| 平移                | **鼠标右键** | 拖动相机平面平移       |
| 缩放                | **滚轮**     | 缩放相机轨道距离       |
| 变焦                | **C**        | 放大指针区域，滚轮调焦 |
| WASD / 空格 / Shift | —            | 自由飞行，Ctrl 加速    |

## 修饰键模式

| 模式     | 修饰键     | 鼠标键                                       |
| -------- | ---------- | -------------------------------------------- |
| 按住     | 按住切换   | 左键旋转、右键平移、滚轮缩放                 |
| 切换     | 按一下切换 | 同上                                         |
| 独立     | 仅切换滚轮 | 旋转/平移键绑定与攻击/破坏键独立时可同时进行 |
| **混合** | 仅切换滚轮 | 点击松开为破坏/放置，拖动为旋转/平移         |

## 配置

- 手感：旋转/平移灵敏度与平滑、缩放速度、轨道距离
- 变焦：焦距、过渡速度、变焦速度、锚点锁定
- 飞行：水平/垂直速度、水平/垂直倍率、加速时间、减速时间
- 模式：操作模式、拖动阈值
- 渲染：中心方块、线框颜色
- 交互：方块距离、实体距离
- 单人：距离同步、本体跟随
- 信息：状态栏、X/Y 坐标

## 构建

```powershell
.\gradlew.bat build                 # 构建三个版本
.\gradlew.bat :v26_2:runClient      # 运行某个版本
```
